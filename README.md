# Beer

Grow barley and hops, malt the grain, boil it in a copper **Brew Kettle** over a campfire and ferment it in a
**Fermenting Barrel** into one of eight beers. Drink from glass mugs, put them on tables, clink them with friends, and
watch the Tipsy meter. Everything has custom 3D models and works with hoppers.

## Features

- **Crops**: Barley (like wheat) and Hops (a perennial on a 3-block pole you pick again and again); both are their
  own seed, found in grass by biome, village chests and from wandering traders
- **Malting**: Barley becomes Malt and Dark Malt in a smoker, furnace or campfire
- **Brew Kettle**: water, 4 grain, 1 or 2 hops and an optional extra, boiled over heat into a Bucket of Wort
- **Fermenting Barrel**: ale when warm, lager beside ice; pale or dark wood; beer gains stars as it ages and never spoils
- **8 styles** (Wheat Beer to Dark Lager), **5 extras** (Honey, Sugar, Cocoa, Sweet Berries, Pumpkin) and
  **4 Tavern Legends** to discover, each with buffs that grow with the stars
- **Tipsy and Cheers**: each mug adds to a Tipsy meter (a wobble, passing out, a hangover; all switchable); drink
  together for Luck and longer effects; put mugs down on any block
- **Automation**: a kettle's tap pours into a barrel, hoppers feed both and bottle aged beer, dispensers fill the
  kettle and harvest the crops
- **Beer Journal** (`/beer journal`): the brewer's guide, styles, extras, legends and recipes, filled in as you brew
- A resource pack served by the plugin itself and stacked with other packs

Works alone or beside [Maty](https://github.com/EightL/maty-plugin).

## Requirements

- Paper `26.3` and Java `25`
- Clients accept the server resource pack (sent on join; optional unless `resource-pack.required` is set)

## Install

1. Run `./gradlew build` or download `beer-<version>.jar`.
2. Put it into `plugins/` and start the server once.
3. Configure `plugins/Beer/config.yml` and run `/beer reload`.
4. Open port `8165` (TCP) for the resource pack, or set `resource-pack.public-url`, or turn hosting off and merge
   `plugins/Beer/beer-pack.zip` into your own server pack. Use a different port from other plugins that host a pack.

## Commands and permissions

| Command | Permission | |
|---|---|---|
| `/beer journal` | `beer.journal` (everyone) | open the Beer Journal |
| `/beer give <item> [amount] [player] [style\|legend\|wood]` | `beer.admin` (op) | give items |
| `/beer grow [stages]`, `/beer plant <x> <y> <z> <barley\|hops> [stage]` | `beer.admin` | grow or plant for testing |
| `/beer place <furniture> <x> <y> <z> [pale\|dark]`, `/beer put <item> <amount> <x> <y> <z> [spec]` | `beer.admin` | place furniture, fill a container |
| `/beer skip [minutes]` | `beer.admin` | finish a boil, or make a barrel ready (and older) |
| `/beer tipsy [player] [level]` | `beer.admin` | show or set the Tipsy level |
| `/beer info`, `/beer reload` | `beer.admin` | loaded crops, reload the config |

## Development

`./gradlew build` builds the jar with the resource pack inside and runs the unit tests. The models, textures and icons
are generated by the scripts in `tools/` (stdlib Python, `python3 -I tools/<name>.py`); `models/` holds the Blockbench
projects they also write. Documentation: <https://eightl-projects.vercel.app/beer/overview>.
